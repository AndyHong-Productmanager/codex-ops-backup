# 보고서 디자인 계약

기존 design-spec.md를 이 문서의 상위 규격으로 사용한다. 웹 애플리케이션이 아닌 A4 인쇄용 조사 보고서다.

## 독자와 정보 순서
내부 의사결정자에게 관계의 확인 범위, 연혁, 반증, 후속 확인 문서를 전달한다. 핵심 판단, 법인 식별, 연표, 상세 근거와 상충, 미해결 부록과 방법, 전체 출처 순으로 배치한다.

## 토큰
ink #17212B, paper #F8F7F3, accent #0B6E69, rule #D6D3CA, muted #5D6770. 서체 Noto Sans CJK KR. 제목 25pt, 장 제목 17pt, 소제목 11pt, 본문 9.5pt, 표 8.6pt, 출처 8pt. 행간 1.65. 간격 3/6/9mm, 페이지 여백 18mm.

## 표면과 계층
밝은 종이색, 짙은 본문, 청록색 제목. 그림자와 장식 배경 없음. 상태는 확인/부분/미확인이라는 문자로 표시한다.

## 재사용 요소
page: 강제 페이지 분리 단위. kicker: 문서 분류. lead: 집행 요약. table: 반복 헤더와 행 단위 보호. figure: 고정 크기 프레임, object-fit contain. sources: URL의 강제 줄바꿈 허용. citation: 줄 안의 출처 표시.

## 접근성과 인쇄
한국어 keep-all, 일반 본문 overflow-wrap anywhere. PDF에서 선택 가능한 텍스트. 본문은 읽기 순서대로 DOM에 배치. SVG는 의미 있는 대체 설명을 제공한다. 화면에서는 페이지 폭을 뷰포트에 맞춘다.

## 동작과 제한
애니메이션 없음. 링크만 탐색 가능. 웹 앱 성능 감사와 React 도구 설치는 인쇄 보고서 범위가 아니다. 수치 그래프가 아닌 기록 기반 시계열 및 관계도 두 개만 생성한다.

## 검수
report-tools 정적 검사, Chrome 인쇄, 전 페이지 PNG 확인, 독립 검수. 지분·법적 승계·계약 유효성 미확인은 시각적으로도 확정 선으로 연결하지 않는다.
