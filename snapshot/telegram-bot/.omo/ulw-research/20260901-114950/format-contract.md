# Format contract

- User instruction received 2026-09-01: write the report as a PDF.
- Binding delivery: Korean PDF, A4 portrait, approximately 12–16 pages, numbered sources, a workflow diagram, a cost-scenario chart, and a limitations section.
- Not included: a DOCX copy, because the user expressly requested PDF only.
- Audience: a patient/family member deciding how to request archived cancer pathology material for a proposed cancer-vaccine workflow.
- Citation rule: every factual claim in the report carries a numbered source. Measured, assumed, and derived numbers are visibly separated.
